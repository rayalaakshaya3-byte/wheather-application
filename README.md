# Weather Checker

A small Flask app that shows current weather for a searched city using OpenWeather.

## Run locally

1. Create and activate a Python virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Set your key in PowerShell: `$env:OPENWEATHER_API_KEY="your_key"`
4. Start the app: `python app.py`
5. Visit `http://127.0.0.1:5000`

Create an API key at [OpenWeather](https://openweathermap.org/api). The key is deliberately not stored in this repository.
